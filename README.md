# 📝 Task Manager

A simple and responsive **Task Manager Web Application** built using **HTML, CSS, JavaScript, and Python**.
The project is designed to help users organize, manage, and track their daily tasks through an easy-to-use interface.

## 🚀 Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ☑️ Mark tasks as completed
* 📋 View and manage your task list
* 🔄 Dynamic task updates using JavaScript
* 📱 Responsive user interface
* 🎨 Clean and simple design
* 🐍 Python backend integration

## 🛠️ Technologies Used

### Frontend

* **HTML5** – Structure and layout
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and task management

### Backend

* **Python** – Backend/server-side functionality

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/task-manager.git
```

### 2. Navigate to the project directory

```bash
cd task-manager
```

### 3. Install Python dependencies

If your project contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 4. Run the Python application

```bash
python app.py
```

### 5. Open the application

Open the local URL shown in your terminal, usually:

```text
http://127.0.0.1:5000
```

## 💡 How It Works

The application uses **HTML and CSS** to create the user interface, while **JavaScript** handles client-side interactions such as adding, editing, completing, and deleting tasks.

The **Python backend** handles server-side functionality and can be extended to store tasks in a database such as SQLite, MySQL, or MongoDB.
